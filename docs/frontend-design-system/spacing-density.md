# Spacing and density

Spacing is tokenized in `tokens/spacing.css` and density in `tokens/density.css`.

- Spacious: homepage hero and high-level system statements.
- Standard: sections, entity cards, and explanatory copy.
- Compact: capability strips, specifications, and route summaries.
- Dense: inspection tables, RFQ metadata, and revision records.

The layout uses `--layout-max`, `--layout-technical`, and `--layout-reading` rather than page-specific widths. Mobile collapses to one column and converts dense grids to readable stacks.
