# Manufacturing OS design DNA

Manufacturing OS is an industrial operating interface for engineers and hardware teams. Its visual language uses quiet surfaces, dark navy structure, cool blue actions, compact metadata, and evidence-first copy.

The system favors borders and spacing over shadows. Pages use a technical canvas with a stable maximum width and a predictable action: upload the current files and request a review. Color communicates state, confidence, or workflow category; it is not decoration.

Every new page should answer three questions quickly: what object or process is this, what decision matters, and what is the next inspectable action?
