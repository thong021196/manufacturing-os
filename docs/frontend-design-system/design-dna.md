# Manufacturing OS design DNA

Manufacturing OS is an industrial operating interface for engineers and hardware teams. The current visual DNA is deliberately premium and deep-blue: a dark navy frame establishes company identity, cool blue is reserved for action and technical emphasis, and white/cool-off-white surfaces give engineering content room to breathe.

The system favors borders, typographic hierarchy, and spacing over heavy shadows or rounded cards. The homepage uses an editorial company rhythm; part, application, capability, quality, and network pages each use a different composition while sharing the same grid, annotation, and action language. Color communicates state, confidence, or workflow category; it is not decoration.

Every new page should answer three questions quickly: what object or process is this, what decision matters, and what is the next inspectable action? The primary RFQ action remains consistent, but supporting composition should fit the page's narrative purpose rather than cloning one template.
