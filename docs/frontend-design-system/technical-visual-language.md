# Technical visual language

Technical figures use a dark navy field, a restrained construction grid, a geometric object, a figure code, and a caption. Feature callouts use A/B/C or numeric markers. Process routes use numbered steps connected by a thin rule. Inspection uses method plus evidence, not a vague quality claim.

Words such as “per drawing”, “drawing-specific”, and “source required” are intentional states. They prevent the frontend from inventing universal tolerances or material facts.
