# Typography

Inter is the current UI face with a monospace companion for technical labels, revision IDs, dimensions, and state. Display and heading sizes are fluid; technical content stays compact.

Use `--type-display` only for the homepage statement. Use `--type-h1` for a technical page title and `--type-h2` for section-level decisions. Metadata and table labels use the monospace face at `--type-label` or `--type-technical`.

Avoid turning every paragraph into a hero. A technical page should allow a buyer to scan a route, evidence, and open requirements without losing the hierarchy.
