# Interaction states

Buttons, links, form fields, tags, and navigation share default, hover, focus, active, disabled, loading, success, warning, and error semantics. Focus uses a visible two-pixel outline and must remain usable on keyboard navigation.

Motion is short and quiet (`--motion-fast`, `--motion-standard`, `--motion-slow`). The reduced-motion media query collapses transitions to zero duration. Motion communicates a state change or hierarchy; it is never decorative.
